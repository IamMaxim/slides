# Что такое агенты и как их есть

Interactive slide deck covering how LLMs and AI agents work — from individual neurons to frontier multi-agent systems.

## Topics

- Neurons, networks, and the transformer architecture
- Tokenization and attention
- How LLMs generate text
- Chat, tool use, and the agent loop
- The harness: compaction, memory, system prompts, skills
- MCP: why it exists, how it's shaped, the ecosystem
- Model internals: dense vs. MoE, the model zoo
- Harness engineering: why, toolkit, verification
- Frontier agents: patterns and the road ahead

## Running locally

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

Navigate with `←` / `→` or `Space`.
